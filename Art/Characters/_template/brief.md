## 레퍼런스 (공정 2단계)

FFBE 맵 캐릭터 한 명. 측정만 하고 생성 입력이나 픽셀 복사에 쓰지 않는다. 아래 목표 수치를 생성 목표로 쓴다.

| 항목 | 내용 |
|---|---|
| 후보 3명과 이유 | 체형·성별, 등신, 머리, 의상 실루엣, 소품 기준 |
| 선택 | 이름, 선택 이유, 승인 날짜 |

| 목표 | 레퍼런스 값 | 허용 범위 | 결과 |
|---|---|---|---|
| 키(장식 포함) | | ±2 | |
| 머리(정수리~턱) | | ±1 | |
| 등신 | | ±0.15 | |
| 정면 폭/키 | | +0.05, 상한 0.78 | |
