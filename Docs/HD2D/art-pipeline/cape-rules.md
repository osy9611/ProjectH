# 망토 도트 표현 규칙

망토 달린 캐릭터를 50도트 키로 옮길 때 쓰는 규칙이다. 외부 파이프라인의 FFBE 망토 분석(`specs/cape_rendering.md`, Bran·Lunera·Ayaka·Charlotte·Aileen 등)을 옮겼다.

2026-11-10에 첫 시험 캐릭터 두 판(외부 파이프라인판, 우리 판)의 망토를 이 규칙과 비교했다. 그 캐릭터는 2026-11-11에 폐기했고, 비교 측정과 적용 제안은 이 문서의 이전 판(커밋 `d3f6e3a`, 아카이브 `ProjectH_ArtArchive/2026-11-11/art-branches.bundle`)에 있다. 그 비교에서 일반 규칙으로 남길 만한 것은 아래 "비교에서 얻은 것"이다.

## FFBE 규칙 (외부 파이프라인 분석)

| 방향 | 형태 | 크기 |
|---|---|---|
| 정면 | 몸통·팔에 가려 위쪽은 거의 안 보임. 무릎~종아리 높이에서 다리 바깥으로 삼각형 자락 | 한쪽 3~6도트 |
| 후면 | 어깨에서 시작해 아래로 넓어지는 사다리꼴. 종아리~발목에서 끝나고 발이 2~6행 보임 | 밑단 폭 = 어깨의 1.3~1.5배 |
| 측면 | 어깨 뒤에서 비스듬히 뒤로 떨어지는 삼각형. 수평으로 날리지도, 몸에 수직으로 붙지도 않음 | 밑단이 몸 뒤로 6~10도트 |
| 공통 | 긴 머리카락은 망토 위에 그리고 외곽선으로 구분. 세로 주름은 1도트 진한 줄을 2~3도트 간격으로 2~4줄 | |
| 색·선 | 2~3톤(밝은 면, 중간, 주름 그림자). 외곽선은 망토보다 진한 같은 계열 또는 따뜻한 테두리색. 밑단에 대비색 줄 1~2개가 있으면 끝이 또렷함 | |

## 비교에서 얻은 것

**근거 재확인 필요:** 캐릭터 하나의 두 판을 비교한 결과다. 다음 망토 캐릭터에서 다시 확인한다.

- 흰 망토는 3~4톤(밝은 면·중간·주름 그림자·테두리 선)으로 줄인다. 24색에 아주 밝은 픽셀 57%인 판은 면이 하얗게 뭉쳤고, 8색·21%인 판은 50도트에서 읽혔다. 순백은 빛 받는 왼쪽 위 가장자리에만 둔다.
- 밑단 위 1~2행의 대비색 줄과 후면 가운데 1도트 갈래 선은 긴 밝은 면을 끊어 끝을 또렷하게 한다.
- 측면 끌림이 몸 뒤로 15도트까지 가면 FFBE 규칙(6~10)보다 길어 면적과 폭/키가 커진다.
- 다른 결과물의 망토 픽셀을 옮겨 붙이지 않는다. 형태 규칙만 가져와 대상 스프라이트 위에서 다시 그린다.
