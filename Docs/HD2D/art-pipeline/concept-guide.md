# 시안 가이드: 키 50도트로 옮겨지는 디자인

시안을 그리거나 의뢰하기 전에 읽는 문서다. 외부 파이프라인의 `specs/concept_guide.md`를 우리 규격에 맞게 옮겼다. 키는 규격 초안의 48~50도트를 기준으로 쓴다.

핵심: 키 50도트에서는 몸 키의 4%(2도트)보다 작은 디테일이 사라진다. 시안 단계에서 무엇을 남길지 정한다.

## 제출물

| 구분 | 제출물 | 조건 | 이유 |
|---|---|---|---|
| 필수 | 정면 전신 | 똑바로 정면, 원근 없음, 대기 자세, 발끝까지, 팔은 몸에서 살짝 뗌 | 정면이 모든 방향의 기준이다 |
| 필수 | 후면 전신 | 정면과 같은 자세·비율 | 생성기는 뒷모습을 추측한다. 머리 묶음, 망토, 등 장식이 있으면 꼭 필요 |
| 필수 | 컬러 칩 | 키 컬러 4~6개 hex | 팔레트 기준 |
| 권장 | 측면 전신 | 머리 길이, 망토처럼 옆에서 형태가 달라질 때 | 망토 측면 형태(`cape-rules.md`) |
| 권장 | 소품 단독 | 무기·소품이 있을 때, 어느 손인지 | 비대칭 판단 |

긴 등신의 일러스트를 그대로 줄이면 얼굴이 5~6도트밖에 안 된다. 픽셀용 정면은 처음부터 약 3등신(머리 14~16도트)으로 그린다. FFBE 실측은 [ffbe-body-reference.md](ffbe-body-reference.md)에 있다.

## 픽셀로 남는 디자인 규칙

### 크기
- 디테일은 몸 키의 4%(2도트) 이상으로 그린다.
- 얇은 선 요소는 1도트(2%) 이상이어야 남는다. 그보다 가늘면 과장해서 1도트로 그린다.
- 패턴은 쓰지 않거나 2~3도트 단위로 크게 반복한다. 체크·레이스·자수는 면 색 하나로 바뀐다.

예: 키 약 96도트 시안을 50도트로 옮겼을 때(외부 파이프라인 시험 캐릭터 실측)

| 요소 | 시안 크기 | 50도트에서 | 판정 |
|---|---|---|---|
| 큰 벚꽃 | 7.4 | 3.8 | 남음 |
| 작은 벚꽃 | 4.4 | 2.3 | 남음 |
| 체크 한 칸, 프릴 한 단 | 2.0 | 1.1 | 1도트 질감으로만 |
| 리본 끈 폭, 베일 주름선 | 1.1 | 0.6 | 1도트로 과장해야 보임 |

### 실루엣
- 실루엣 키 3개는 몸 밖으로 나오게 한다.
- 머리카락·팔·소품과 몸 사이에 1~2도트 틈을 둔다. 붙으면 한 덩어리로 보인다.
- 몸에서 떨어진 요소(불꽃, 꽃잎, 오라)는 스프라이트에 그리지 않는다. 이펙트로 따로 만든다.
- 정면 폭은 키의 0.78배 이하로 한다(FFBE 정면 최대). 트윈테일·망토가 넓게 벌어지면 넘기 쉽다.

### 색
- 순검정은 쓰지 않는다. 검은 옷은 남색·갈색·보라 쪽으로 기운 어두운 색으로 칠한다.
- 인접한 두 색은 명도가 확실히 다르게 한다. 색상만 다르면 50도트에서 구분되지 않는다.
- 흰 옷이 대부분이면 순백은 빛 받는 면에만 쓰고 나머지는 연한 중간톤으로 칠한다. 낮 장면의 밝기 상한(규격 문서)에 걸린다.

### 피할 것

| 요소 | 문제 | 대안 |
|---|---|---|
| 반투명 재질(베일, 얇은 망토) | 알파는 0과 255만 쓴다 | 불투명한 연한 색 + 가장자리만 다른 색 |
| 빛·오라·파티클 | 조명과 충돌하고 떨어진 픽셀이 된다 | 이펙트로 분리 |
| 그라데이션 | 띠처럼 끊어진다 | 2~3단계 단색 |
| 바닥 그림자 | 엔진이 그린다 | 그리지 않음 |
| 정면에서 안 보이는 핵심 디자인 | 정면이 기준이라 빠진다 | 정면에서 보이게 두거나 후면 시안 제출 |

## 넘기기 전 확인

- [ ] 정면 전신(약 3등신, 원근 없음, 대기 자세, 발끝)
- [ ] 후면 전신
- [ ] 컬러 칩
- [ ] 실루엣 키 3개가 몸 밖으로 나옴, 몸과 1~2도트 틈
- [ ] 디테일 2도트 이상, 패턴 없음 또는 큰 반복
- [ ] 순검정·반투명·발광·그라데이션 없음
- [ ] 비대칭 소품과 어느 손인지
